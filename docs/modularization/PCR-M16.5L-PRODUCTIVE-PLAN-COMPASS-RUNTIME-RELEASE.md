# PCR M16.5L — Productive Plan Compass Runtime Release

## Purpose

M16.5L packages the M16.5K productive embedded Plan Compass as a new immutable
Integration candidate. This release exposes the next visible feature-migration
slice for desktop and mobile review; it does not declare Plan/Places/Booking or
the complete visual redesign finished.

The active entry, App Shell fallback, Trip Context import, diagnostics,
force-update target and Service Worker cache advance together. The official
Compass vector bytes remain unchanged; only Consumer composition and motion
use the layered face, native two-ended needle and hub.

## Validation and release lock

The candidate includes the centered eight-direction Plan stage, shared-element
flight from the top-left Luvia brand, mobile no-scroll sizing and the real
Places/Timeline/Booking/Routes owner destinations. The separate navigation
entry `Luvia Compass` still opens Intelligence directly.

Main and Production remain locked. Places search/map composition, Booking and
all remaining signed-in feature stages continue as explicit parity work. An
immutable technical Preview is not joint visual acceptance.

No database/schema/RPC/RLS/bucket migration, Supabase Edge Function mutation,
secret mutation, manual Cloudflare configuration change, Main promotion or
Production deployment belongs to M16.5L.

## Rollback

Rollback is an immutable redeployment of the M16.5J Integration runtime or a
forward-only corrective release. No history rewrite or data rollback is needed.
