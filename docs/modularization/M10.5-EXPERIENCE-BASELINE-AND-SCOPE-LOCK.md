## Ownership classification

- Experience owns visual semantics, shared tokens, component/state/motion/accessibility policy and native presentation mappings.
- The Web adapter owns DOM/CSS-variable projection only and stores no product or domain truth.
- Consumer owns App Shell placement and composition of the global trigger.
- Intelligence owns the assistant response flow and consumes Experience semantics as a public contract.
- `overlay-host.v1` remains Platform-owned interaction lifecycle policy.
- Journey / Timeline remains a separately reserved cross-domain aggregator and is not included in this slice.

2. Add an explicit Web adapter that projects the contract to CSS custom properties and a read-only compatibility binding.
3. Convert the old Design System global into a compatibility facade over `experience.v1`; do not create a second design truth.
4. Add a narrowly scoped Experience CSS foundation for new primitives and global focus/reduced-motion semantics; do not bulk-move or rewrite feature CSS.
